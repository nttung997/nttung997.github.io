# Skyhold Survivor

Portrait survival shooter. Native Canvas, CSS, and JavaScript. No build step. Open [index.html](./index.html) or visit `/game/`.

Move with WASD, arrows, or a drag on the battlefield. Pick one of six weapons before the run; it stays locked and fires on its own (hold Space if auto-fire is off). Level-ups pause combat and offer three choices. Phase rounds and Volatile rounds are mutually exclusive. P or Escape pauses. Losing window focus does not. Sound, volume, and the best score are saved locally. There is no music.

Logic is in [game.js](./game.js). Layout is [index.html](./index.html) and [style.css](./style.css). The canvas is a 480×680 logical space. Plans are in [ROADMAP.md](./ROADMAP.md).
