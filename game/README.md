# Skyhold Survivor

A portrait survival shooter built with native Canvas, CSS, and JavaScript. No installation, build step, or external assets are required. Open [index.html](./index.html) directly in a modern browser or visit `/game/` on the deployed site.

## Play

- Start a run and move with WASD or arrow keys. On mobile, drag inside the battlefield. You can move across the arena, above the base.
- **Pick one of six weapons before combat; it is locked for the run.** The weapon is the run's only damage source and fires on its own cooldown. Level-ups can rank it up (rank 1 → 3) or, once it is maxed and you own its paired passive, offer its evolution. Evolutions replace the base weapon, start ready, and stop appearing afterwards.
- Your weapon aims automatically. Disable auto-fire and hold Space for manual firing. Aimed weapons turn toward the nearest live, visible enemy, marked with a gold reticle; Rad instead targets the enemy closest to leaking through. Only the Orbital drone ignores aim entirely.
- **Blaster** — aimed burst every second. Its rank track is its shot pattern: **1×1 → 2×2 → 3×3** (bursts × parallel bullets). Bursts start 200 ms apart, 8 pixels apart with identical velocity; at rank 3 that is nine bullets per second. Base damage is 40, +25% per Overcharged rank. Evolution: **Arc laser** (requires Phase rounds) replaces it with a 5 Hz line beam that pierces every enemy on the aim line.
- **Gravity** — aimed rounds charge enemies (up to 6 charges, decaying after 3 seconds). Charged enemies are magnets: they pull neighbours toward themselves, crush overlapping enemies, and buckle under their own gravity, so a lone enemy still dies. Evolution: **Singularity** (requires Volatile rounds) adds a stronger, wider pull.
- **Cryo** — aimed frost rounds that stack slow on impact and in a small burst. Each stack reduces speed by a percentage scaled to the enemy's max HP, so trash freezes in a few stacks while tanks and siege carriers need many. Stacks persist until the target reaches 100% slow; then it freezes and shatters — on a short timer or immediately when hit — and the shatter executes it outright. Cryo deals no direct damage. Cryo runs are never offered Cryo rounds (the rounds already stack slow). Evolution: **Absolute zero** (requires Volatile rounds) spills a slow stack onto nearby enemies when one reaches 100% slow.
- **Rad** — aimed rounds add permanent radiation stacks (2 + rank per hit, capped at 40, no expiry). Damage per second is linear in stacks, so sustained fire ramps. Auto-aim picks the enemy about to reach the outpost, which spreads stacks across the field. Evolution: **Meltdown** (requires Overcharged rounds) speeds the burn and spreads half the stacks to nearby enemies when a host dies.
- **Orbital drone** — a drone sweeps a wide contact zone around your defender; enemies inside take contact damage, scaled up for larger bodies. No aim required. Evolution: **Twin orbit** (requires Overcharged rounds) doubles the contact damage.
- **Mines** — drops armed charges across a rear arc, covering most of the lane. A charge detonates on contact for a large blast that scales with enemy size; the oldest charge detonates when the six-charge cap is exceeded. Evolution: **Cluster mines** (requires Volatile rounds) scatters three sub-charges on every detonation.
- Passives are shared by all weapons: **Overcharged rounds** (weapon damage), **Phase rounds** (piercing), **Volatile rounds** (explosions), **Cryo rounds** (slow), and **Emergency repair**. Phase rounds and Volatile rounds are mutually exclusive — taking one removes the other from every future level-up. Ranks have caps; capped upgrades stop appearing. The level-up pool offers the locked weapon's next rank, passives, its evolution once ready, and repair when the base is hurt.
- Kills automatically award XP. Each level pauses combat and offers three choices. Click a card, tap it, or press 1, 2, or 3 to choose. XP beyond a level threshold carries over; multiple earned levels each get a separate choice. Taking a weapon rank resets its cooldown so the upgrade feels immediate.
- Enemies are tougher than the original tuning: base health is 46 for drones, 30 for runners, 170 for tanks, and 3,200 for a siege carrier. Health, speed, and damage all scale with the threat level.
- Hostiles spawn continuously, with no waves or intermissions. Threat rises every 30 seconds, speeding up spawns and strengthening new enemies. A siege carrier joins the field every four threats. There is no win state; survive as long as you can.
- Enemies reaching the base, touching your defender, and boss projectiles damage base integrity. A boss reaching the base destroys it outright. There is no damage-reduction passive: survival comes from killing things and using Emergency repair.
- Press P or Escape to pause. Losing window focus or switching tabs does **not** pause combat: only held movement input is released, so the run keeps going and time away costs you. Upgrade selection freezes the simulation.
- Sound and auto-fire are optional and persisted locally. The survivor best score is stored locally when browser storage is available. Restart clears the current weapon, build, and XP.

## Install and offline

The game ships a web manifest (`manifest.webmanifest`) with SVG icons, so it can be installed to a home screen or desktop. `sw.js` caches the shell for offline play: game code and documents are network-first so edits are never trapped behind a stale cache, while styles, icons, and the manifest are cache-first.

## Development

The game uses a fixed 480 × 680 logical coordinate system and scales to the available width. The canvas backing store is sized from the element's real CSS width times `devicePixelRatio` and drawn through a matching `setTransform`, so vector art stays crisp on high-DPI screens while drawing code keeps using logical coordinates. Upgrade and weapon definitions, XP progression, auto aim, input, simulation, and drawing live in [game.js](./game.js). Each of the six weapons is data plus a `fire` function in the `weapons` registry, driven by one cooldown in `update()`; the six evolutions live in a separate `evolutions` registry and apply their unique effect in the shared mechanics. The layout and level-up dialog live in [index.html](./index.html) and [style.css](./style.css).

Serve the repository with any static web server when testing over HTTP, for example `python -m http.server 8000`, then open `http://localhost:8000/game/`.

Run `node --test game/game.test.cjs` from the repository root. The dependency-free Node tests cover XP, distinct and capped choices, overflow levels, freezing during upgrade selection, weapon locking and the six-weapon roster, pierce/blast mutual exclusion, Cryo hiding the frost passive, automatic targeting, manual firing, movement bounds, blaster ranks and all three shot patterns, piercing, splash and frost, defeat/restart, 1 Hz timing, every evolution gate and replace path (Arc laser, Singularity, Absolute zero, Meltdown, Twin orbit, Cluster mines), Cryo slow stacks and max-HP-scaled potency, the 100% execute (including bosses), Rad stacking and its leak-prediction aim, Gravity magnetising and crushing, Orbital drone contact damage, Mines arming and detonation, threat escalation, siege-carrier spawns, focus-loss not pausing, and survival across a long endless run for every weapon.
